Internals

The internal functions and types of HMatrices, which may change without notice: those of the cluster trees, the compressors and the assembly below, and those of the arithmetic (products, factorizations and their executors) on their own page.

HMatrices.PermutedMatrix — Type
PermutedMatrix{K,T} <: AbstractMatrix{T}

Structure used to represent the permutation of a matrix-like object. The original matrix is stored in the data::K field, and the permutations are stored in rowperm and colperm.

HMatrices.VectorOfVectors — Type
struct VectorOfVectors{T}

A simple structure which behaves as a Vector{Vector{T}} but stores the entries in a contiguous data::Vector{T} field. All vectors in the VectorOfVectors are assumed to be of size m, and there are k of them, meaning this structure can be used to represent a m × k matrix.

Similar to a vector-of-vectors, calling A[i] returns a view to the i-th column.

See also: newcol!

HMatrices.RkMatrix — Type
mutable struct RkMatrix{T}

Representation of a rank r matrix M in outer product format M = A*adjoint(B) where A has size m × r and B has size n × r.

Two additional fields describe the factors, when this information is available:

  • orthogonality::Symbol: which factors have mutually orthogonal columns: :none, :A, :B, or :AB (e.g. a truncated SVD, A = U*Σ and B = V).
  • truncation_error::Vector{Float64}: truncation_error[i] is an estimate of the Frobenius norm of the error made by keeping only the first i columns of the factors (the last entry estimates the error of R itself). It is exact (up to rounding) for a truncated SVD of an exact matrix, and an estimate otherwise (e.g. the error of a PartialACA, combined with the one of its recompression). An empty vector means that no estimate is available.

Constructing an RkMatrix from A and B only, or assigning R.A or R.B, resets these fields to :none and Float64[].

HMatrices._aca_partial — Function
_aca_partial(K, irange, jrange, atol, rmax, rtol, samples, buffer = nothing)

Internal function implementing the adaptive cross-approximation algorithm with partial pivoting. The returned R::RkMatrix provides an approximation to M = K[irange,jrange] of rank at most rmax, which is expected to satisfy |M - R| < max(atol,rtol*|M|), but this inequality may fail to hold due to the various errors involved in estimating the error and |M|.

source
HMatrices._aca_partial_pivot — Method
_aca_partial_pivot(v,I)

Find in the valid set I the index of the element x ∈ v maximizing its smallest singular value. This is equivalent to minimizing the spectral norm of the inverse of x.

When x is a scalar, this is simply the element with largest absolute value. Return -1 if I has no valid index.

This general implementation should work for both scalar as well as tensor-valued kernels; see https://www.sciencedirect.com/science/article/pii/S0021999117306721 for more details.

source
HMatrices._aca_residual_sample — Method
_aca_residual_sample(K, A, B, I, J, buffer, irange, jrange, ns, tol, r)

Check the residual K[irange, jrange] - A*Bᴴ at ns entries, and return the unused row of the largest residual found if it shows an error above tol, and -1 otherwise.

Half of the entries are at pseudo-random positions, from which the Frobenius norm of the residual is estimated. The other half pair the unused rows of A and of B of the smallest norms (kept in buffer.ra and buffer.rb), which the approximation leaves out: an entry there more than 10 times above the average allowed by tol means that ACA missed part of the block.

HMatrices._rtol — Method
_rtol(rtol, atol, rank, T)

The relative tolerance used to compress a matrix with entries of type T, where R is the real type underlying T. If rtol is nothing, it is sqrt(eps(R)), or the accuracy attainable with R (10eps(R)) if atol or rank is given. Throw an ArgumentError if rtol is below that accuracy.

An rtol of zero is raised to that accuracy, so that an atol too small for a block does not compress it to full rank.
